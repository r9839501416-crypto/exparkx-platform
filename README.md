# Exparkx Platform

Production-oriented Next.js App Router implementation for Exparkx, "The All-In-One Startup Ecosystem."

## Setup

1. Copy `.env.example` to `.env.local`.
2. Add Supabase project URL and anon key.
3. Run the SQL in `supabase/schema.sql`.
4. Install dependencies with `npm install`.
5. Start locally with `npm run dev`.

The app is Vercel-compatible and suitable for Hostinger Node hosting where Next.js apps are supported.
